# Changesets

A change users can see adds a file here: run `bun run changeset` and commit
the result. On `0.x`, pick `patch` for a feature or a fix, and `minor` for a
breaking change.

Merging to `main` opens or updates a "Version Packages" pull request. Merging
that pull request publishes to npm. See [CONTRIBUTING.md](../CONTRIBUTING.md).
