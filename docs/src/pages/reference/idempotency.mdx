```ts twoslash
import { Idempotency } from "effect-idempotency";
```

| Export                                | Kind       | What it is                                             |
| ------------------------------------- | ---------- | ------------------------------------------------------ |
| [`Service`](#service)                 | Function   | Declares an idempotency middleware class.              |
| [`layer`](#layer)                     | Function   | Provides a middleware declared with `Service`.         |
| [`Options`](#options)                 | Interface  | The options of `layer`.                                |
| [`FingerprintBody`](#fingerprintbody) | Annotation | Whether an endpoint's body is part of its fingerprint. |

## Service

Declares an idempotency middleware: an `HttpApiMiddleware.Service` class with
the idempotency errors already declared.

```ts twoslash
import { Context } from "effect";
import { Idempotency } from "effect-idempotency";

class CurrentUser extends Context.Service<
  CurrentUser,
  { readonly id: string }
>()("app/CurrentUser") {}
// ---cut---
class PaymentIdempotency extends Idempotency.Service<
  PaymentIdempotency,
  { requires: CurrentUser }
>()("app/PaymentIdempotency") {}
```

**Type parameters**

| Parameter | Description                                                                                        |
| --------- | -------------------------------------------------------------------------------------------------- |
| `Self`    | The class being declared.                                                                          |
| `Config`  | Optional. `{ requires: ... }` names the services the scope reads. Leave it out when it reads none. |

**Arguments**

| Argument | Type     | Description                                                        |
| -------- | -------- | ------------------------------------------------------------------ |
| `id`     | `string` | The identifier of the service, such as `"app/PaymentIdempotency"`. |

The class is part of the API definition, so it can be shared with a client.
Add it to an endpoint, a group or an API with `.middleware(...)`.

The services in `requires` must be provided by a middleware added to the
endpoint after this one, which runs outside it. See
[Scope](/behaviour/scope#run-authentication-first).

## layer

Provides an idempotency middleware declared with [`Service`](#service). The
result is a layer that requires an
[`IdempotencyStore`](/reference/idempotency-store).

```ts twoslash
// @filename: Api.ts
// [!include ~/snippets/Api.ts]

// @filename: Server.ts
import { Effect, Layer } from "effect";
import { Idempotency, IdempotencyStore } from "effect-idempotency";
import { CurrentUser, PaymentIdempotency } from "./Api.ts";
// ---cut---
const PaymentIdempotencyLive = Idempotency.layer(PaymentIdempotency, {
  scope: Effect.map(CurrentUser, (user) => user.id),
  retention: "24 hours",
  lockExpiry: "5 minutes",
}).pipe(Layer.provide(IdempotencyStore.layerMemory));
//       ^?
```

**Arguments**

| Argument  | Type                   | Description                                                          |
| --------- | ---------------------- | -------------------------------------------------------------------- |
| `service` | A class from `Service` | The middleware to provide.                                           |
| `options` | [`Options`](#options)  | The scope, the retention, the lock expiry and the stored size limit. |

**Returns** `Layer.Layer<Id, never, IdempotencyStore>`, where `Id` is the
middleware class.

For each request the middleware reads the key and claims it in the store.
[How a request is answered](/behaviour/requests) lists every outcome.

## Options

The options of [`layer`](#layer).

| Option           | Type                              | Default       | Description                                                                |
| ---------------- | --------------------------------- | ------------- | -------------------------------------------------------------------------- |
| `scope`          | `Effect.Effect<string, never, R>` | Required      | Who a key belongs to, read once per request. `R` is what `requires` names. |
| `retention`      | `Duration.Input`                  | `"24 hours"`  | How long a stored response is replayed.                                    |
| `lockExpiry`     | `Duration.Input`                  | `"5 minutes"` | How long a request may hold a key before another request may take it.      |
| `maxStoredBytes` | `ByteSize.Input`                  | `"1 MiB"`     | The largest response body that is stored.                                  |

- **`scope`**: a key is unique within its scope, so two callers that send the
  same key do not see each other's responses. Return the caller's id on an API
  with accounts. See [Scope](/behaviour/scope).
- **`retention`**: counted from when the handler finished. After it the key is
  new. See [What is stored](/behaviour/stored-responses).
- **`lockExpiry`**: it frees the key of a process that died mid-request. It
  counts for a request that is still running too, streamed response included,
  so make it longer than the slowest handler. See
  [Disconnects and failures](/behaviour/failures#a-process-that-dies).
- **`maxStoredBytes`**: a larger response is sent whole but not stored, and its
  key is released, so a retry runs the handler again. It applies to streamed
  responses too, and bounds the memory their copy takes. See
  [Streams and uploads](/behaviour/streams#the-size-limit).

A `Duration.Input` is, for example, a `Duration`, a number of milliseconds, or
a string such as `"30 seconds"`. A `ByteSize.Input` is, for example, a number
of bytes, or a string such as `"512 KiB"` or `"10 MiB"`.

## FingerprintBody

An endpoint annotation: whether the body is part of what makes two requests
the same request. It is `true` unless an endpoint, or its group, says
otherwise.

```ts twoslash
// @filename: Api.ts
// [!include ~/snippets/Api.ts]

// @filename: Upload.ts
import { Schema } from "effect";
import { HttpApiEndpoint, HttpApiSchema } from "effect/http-api";
import { Idempotency, IdempotencyKey } from "effect-idempotency";
import { PaymentIdempotency } from "./Api.ts";
// ---cut---
const upload = HttpApiEndpoint.post("upload", "/receipts", {
  headers: Schema.Struct({ "idempotency-key": IdempotencyKey.FromHeader }),
  payload: HttpApiSchema.StreamUint8Array(),
  success: Schema.Struct({ id: Schema.String }),
})
  .middleware(PaymentIdempotency)
  .annotate(Idempotency.FingerprintBody, false);
```

| Value   | The middleware                                                                                                          |
| ------- | ----------------------------------------------------------------------------------------------------------------------- |
| `true`  | Reads the whole body before the handler, and compares it byte for byte. The handler reads the body from memory.         |
| `false` | Leaves the body for the handler to stream. Compares the method, path, query string, `Content-Digest` and `Repr-Digest`. |

See [Streams and uploads](/behaviour/streams#leaving-the-body-out-of-the-fingerprint).

## errors

The errors every idempotency middleware declares, as a tuple of the four
classes of [`IdempotencyError`](/reference/idempotency-error). `Errors` is its
type.

```ts twoslash
import { Idempotency } from "effect-idempotency";

Idempotency.errors;
//          ^?
```

`Service` passes it as the middleware's `error`, which is what puts the four
problems in the OpenAPI document and in a generated client's error channel.

## replayedHeader

The name of the header a replayed response carries, with the value `true`.

```ts twoslash
import { Idempotency } from "effect-idempotency";

Idempotency.replayedHeader;

```
